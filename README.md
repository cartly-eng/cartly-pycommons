# cartly-pycommons

Shared building blocks for Cartly Python services.

- `cartly_commons.logging` — single-line JSON logs with trace correlation
- `cartly_commons.http` — outbound call timing helpers

Install (services pin a tag):

```
cartly-pycommons @ git+ssh://git@github.com/prateekkanurkar-cmd/cartly-pycommons.git@v1.3.2
```
